# Unity Tools for Staple Engine

This is an unity package that allows exporting unity scenes and materials to [Staple Engine](https://github.com/Staple-Engine/StapleEngine).

Please note this is a work in progress, and is not fully ready for production, but helps!

## Installation

Add this as a git package to Unity. Should work with unity 2018+, but wasn't tested in a wide range of unity versions.
